# Виртуальная лаборатория моделирования фармацевтических процессов

Образовательная веб-платформа для учебной симуляции технологии твёрдых капсул (цифровой двойник процесса).

База данных, регистрация пользователей и нормативно значимые электронные подписи в эту версию не входят. Журнал и массы существуют только в текущей сессии браузера.

## Запуск

```bash
npm.cmd install
npm.cmd run dev
```

Проверки:

```bash
npm.cmd test
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
```

## Учебная модель процесса

Поддерживаются два маршрута:

- **Прямое смешивание порошков** — сушка гранулята не требуется.
- **Влажная грануляция** — сушка выполняется в сушильном шкафу. Лабораторный эксикатор не заменяет производственную сушку.

Рецептуры в каталоге помечены как модельные и не являются составами зарегистрированных препаратов.

Аналитические хроматограммы, спектры и числовые испытания КК помечены как **модельные данные**.

Ориентиры: ICH Q8(R2), ICH Q9(R1), ICH Q10, принципы GMP-документирования, типовые объёмы пустых твёрдых капсул из каталогов производителей оболочек, ориентировочные диапазоны вспомогательных веществ по справочникам эксципиентов. Конкретные статьи ГФ РК / ГФ ЕАЭС требуют сверки актуального издания.

## Что умеет лаборатория

- Два маршрута: прямое смешивание и влажная грануляция. Граф операций блокирует пропуск обязательных стадий; перемещение объекта в другую зону стадию не заменяет.
- Многокомпонентная модельная рецептура с пересчётом при изменении размера серии и материальным балансом.
- Каталог весов, смесителей (V, двухконусный, барабанный, лопастной), мельницы, сита, сушильного / вакуумного шкафа, капсуляторов и обеспыливателя. Эксикатор — вспомогательная посуда, не сушильный аппарат.
- 3D-перетаскивание контейнеров и инструментов; загрузка в ближайший аппарат; деление и объединение порций с сохранением массы.
- Таймеры аппаратов: операция засчитывается только после выдержки заданного времени (учебный масштаб 1 мин процесса ≈ 5 с). Пауза / стоп до срока не завершают стадию.
- Испытания КК и спектры помечены как **модельные данные**.

## Ограничения

- 3D-модели процедурные (учебные), не аттестованные GLB конкретных серийных аппаратов.
- Характеристики оборудования указаны как типичный класс или учебная заглушка, не как паспорт конкретной серийной модели.
- Нет сохранения серии на сервере. Журнал существует только в текущей учебной сессии и не является GMP-записью с электронной подписью.
- Учебный масштаб времени не равен промышленному циклу.
