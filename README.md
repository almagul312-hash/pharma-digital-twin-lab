# Виртуальная лаборатория моделирования фармацевтических процессов

Публичная демонстрационная версия образовательной платформы для разработки цифровых двойников фармацевтических технологических процессов.

База данных, регистрация пользователей и цифровые расчёты в эту версию не входят.

## Запуск

```bash
npm.cmd run dev
```
